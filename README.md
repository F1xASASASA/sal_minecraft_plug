# Tag (Салочки) — плагин для Paper 1.21.x

## Сборка

В корне (там где `pom.xml`) выполни:

```bash
mvn clean package
```

Готовый `.jar` появится в `target/Tag-1.0.0.jar`. Кинь его в `plugins/` сервера.

Требуется JDK 21+ и Maven.

## Команды

- `/tag start` — запустить игру (сначала идёт голосование)
- `/tag stop` — остановить
- `/tag reload` — перезагрузить конфиг
- `/tag show` — показать текущий конфиг и состояние
- `/tag setpoint <lobby|hunter|runner1|runner2|runner3>` — установить точку спавна по своей позиции
- `/tag setvoid` — установить Y-уровень "пустоты" по своей позиции

Алиас: `/salochki` работает так же как `/tag`.

## Как устроено

1. **Лобби/голосование** (`VOTING`): всем дают железный топор. ПКМ — голос за охотника. По истечении таймера — старт.
2. **Игра** (`PLAYING`): один охотник, остальные бегуны (распределяются по 3 спавнам). Охотник с деревянным мечом ловит бегунов. У охотника фора 5 сек слоунессом.
3. **Поимка**: охотник бьёт бегуна → бегун становится спектатором. Урон обнуляется, реальной смерти нет.
4. **Падения**: бегун падает в воид → выбывает. Охотник падает → респавн через 5 сек на стартовой точке.
5. **Конец**: все бегуны пойманы → охотник победил. Время вышло, бегуны живы → бегуны победили.
6. **Возврат**: через `endTime` секунд все возвращаются в лобби.

## Файл конфига

`plugins/Tag/config.yml` — точки спавнов, тайминги, мин. игроков, Y-уровень воида. После правки — `/tag reload`.
